# TogetherWeTri 統合サイト（英語・日本語・韓国語）

TogetherWeTri 全体のサイトに、日本支部のページ（「日本支部」タブ）をまとめた1つのサイトです。

## ページ構成

| メニュー | アドレス | 内容 |
|---|---|---|
| ホーム | `#home` | 全体の紹介、韓国支部・日本支部 |
| 私たちについて | `#about` | 目標、設立の背景、これまでの歩み、キャラクター紹介 |
| AEIF採択事業 | `#aeif` | 韓国支部のAEIF事業、成果、レポート |
| 日本支部 | `#japan` | 概要・イベント・ニュース・メンバーの4タブ |
| お問い合わせ | `#contact` | フォーム、メール、参加の方法、よくある質問 |

日本支部のタブは `#japan-events`（イベント）、`#japan-news`（ニュース）、`#japan-members`（メンバー）のように直接リンクできます。
旧アドレス `#events` `#news` も自動で新しいタブに移動します。

## 更新のしかた

ふだん編集するのは **data.js だけ** です。

- メールアドレス・フォーム・SNS …… `SITE`
- 日本支部のメンバー …… `MEMBERS`
- 日本支部のイベント …… `EVENTS`
- 日本支部のニュース …… `POSTS`
- 問い合わせの種類 …… `TOPICS`（`to: "japan"` の項目は日本支部アドレス宛て）

文章は `en`（英語）・`ja`（日本語）・`ko`（韓国語）で書けます。`ko` がない項目は、韓国語表示のときに英語で表示されます。

写真・PDF はリポジトリの一番上（index.html と同じ場所）にアップロードし、ファイル名だけを data.js に書きます。

**全体のメールアドレス**：`SITE.email` が空欄の間は、日本支部のアドレスだけが表示され、すべての問い合わせがそこに届きます。全体用のアドレスができたら入れてください。

## 公開のしかた（GitHub Pages・無料）

1. 全体用の GitHub アカウントで、新しいリポジトリ（Public）を作ります。
2. 「Add file」→「Upload files」で、このフォルダの中身を**すべて**アップロードします（フォルダごとではなく、中のファイルを一番上に）。
3. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして Save。
4. 数分後、`https://アカウント名.github.io/リポジトリ名/` で公開されます。
5. （任意）index.html の `og:image` を `https://アカウント名.github.io/リポジトリ名/og.png` に書き換えると、SNSでのリンク表示に画像が出ます。

## 旧日本支部サイトからの転送

旧サイト（togetherwetri-japan リポジトリ）の訪問者を新サイトに送るには：

1. 同梱の `redirect-for-old-japan-site/index.html` を開き、`NEW_URL` を新しいサイトのURLに書き換えます。
2. 旧リポジトリの `index.html` をこのファイルで置き換えます（他のファイルは残しても消してもかまいません）。

旧サイトの各ページは、新サイトの日本支部タブの対応するページに自動で移動します。
